Setup guide

Five minutes from a fresh download to a working crab on your taskbar.

Step 1

Download Pebble

Pebble ships as a Windows folder. Grab the latest release zip and extract it anywhere — your Downloads folder is fine. Inside you'll find Pebble.exe alongside its dependencies.

Size: 63 MB  ·  SHA-256: 9ba4d8777c6449e9028e1ad93bca1845c5ad4a2bd24d86f0bbb51dafaae105ee

Step 2

First launch

Double-click Pebble.exe. Because v0.3.0 isn't yet code-signed, Windows will pop up a SmartScreen warning the first time:

Windows protected your PC — click More info, then Run anyway.

This is expected for unsigned apps. v0.4 will ship signed, after which this warning will go away.

Step 3

Setup wizard

A wizard launches the first time. It walks you through:

  1. Hardware scan — Pebble checks your CPU/RAM/GPU and recommends a local model size.
  2. Pick a model — choose any mix of local (Ollama) and cloud (Claude, GPT, Gemini). At least one is required.
  3. Connect Gmail & Calendar (optional) — see Step 4 below.
  4. Done — the wizard closes, a crab appears on your taskbar.
Dry-run is on by default. Every action Pebble would take is logged to a preview file instead of firing for real. Use /review-drafts in chat to inspect, and /dry-run off in Settings when you trust it.
Step 4

Connect Gmail & Calendar

Pebble doesn't ship with shared Google credentials — you bring your own. The wizard's "Connect Gmail & Calendar" step walks you through five short Google Cloud Console steps:

  1. Open Google Cloud Console and sign in.
  2. Create or select a project, then enable the Gmail API and Google Calendar API.
  3. OAuth consent screen → External → Testing is fine.
  4. Credentials → Create credentials → OAuth client ID → Application type: Desktop.
  5. Download the JSON file Google gives you, then paste its contents into the wizard's textarea and click Save & continue.

The pasted credentials are stored at ~/.pebble/secrets/google_oauth.json on your machine and never leave it. You can also skip this step and come back to it later from Settings — but Gmail/Calendar features won't work until you do.

Why BYOC? Pebble is open-source — bundling a shared OAuth client means everyone's tokens trust a single secret we'd need to rotate publicly. Bringing your own keeps the trust boundary clean.
Step 5

Connect Obsidian and others

Pebble's persistent memory lives in your Obsidian vault. After the wizard, type one of these in chat to connect more sources:

  • /connect obsidian C:\path\to\Vault — point Pebble at your Obsidian vault
  • /connect canvas <base-url> <access-token> — Canvas LMS for course deadlines
  • /connect github <pat> — GitHub PRs and issues
  • /connect spotify — playback control via OAuth
  • /connect slack <workspace> <token> — per-workspace Slack
  • /connect notion <api-key> — Notion pages + databases

Each connection writes only to ~/.pebble/config.json on your machine. /status shows what's connected; /disconnect <name> removes one.

Step 6

Daily commands

The slash commands you'll use most often:

  • /briefing — generate a morning briefing (calendar + email + deadlines)
  • /wrapup — evening reflection + tomorrow preview, appended to your daily note
  • /exam-prep <course> <YYYY-MM-DD> — backward-from-deadline study plan
  • /review-drafts — see what dry-run actions Pebble has prepared
  • /how-am-i-doing — observability summary
  • /help — full slash-command reference
Troubleshooting

If something doesn't work

SmartScreen blocks Pebble.exe on first launch. Click More info then Run anyway. v0.3.0 is unsigned; v0.4 will ship signed.

The crab doesn't appear on the taskbar. The wizard window might still be open behind another app — alt-tab to find it. If it's truly gone, run Pebble.exe again; the wizard skips if setup is complete.

"OAuthNotConfigured" when I try /connect google. You skipped the Google step in the wizard, or your ~/.pebble/secrets/google_oauth.json file is malformed. Open Settings → Modules → Google to retry, or re-run the wizard.

No internet during model setup. The wizard needs to either reach Anthropic/OpenAI/Gemini (to verify your API key) or have an Ollama server already running locally. If you're offline, skip cloud and install Ollama first.

I want to report something else. Open a GitHub issue at github.com/SamEthanMathew/Pebble/issues. Attach the last 50 lines of ~/.pebble/errors/<date>.jsonl if there's a relevant error row.

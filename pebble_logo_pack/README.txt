Pebble Logo Pack

Included versions:
- Full logo: transparent PNG, cream background JPG, white background JPG, dark-mode PNG
- Crab icon only: transparent PNG, cream background JPG, app icon sizes, favicon ICO
- Wordmark only: transparent PNG, black/white versions
- Monochrome versions: black and white transparent PNGs
- SVG wrappers: embedded PNG versions for easy use in web projects

Recommended usage:
- Website header: pebble-logo-full-transparent.png
- Dark UI/header: pebble-logo-full-transparent-dark-mode.png
- App icon: pebble-app-icon-1024x1024-cream-bg.png or pebble-crab-icon-512x512-transparent.png
- Favicon: pebble-favicon.ico
- Social/avatar: pebble-app-icon-512x512-cream-bg.png
- Product docs/slides: pebble-logo-full-cream-bg.jpg

Note:
The SVG files are raster-embedded wrappers, not manually redrawn vector SVGs. They are useful for placement in web projects, but a true production vector logo should be traced/refined later in Figma/Illustrator.
